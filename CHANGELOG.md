# Changelog

## 0.1.0a1

Experimental alpha with a typed Python library, local CLI and optional authenticated HTTP/MCP service.

- Durable sessions, attributed contributions and handovers.
- Exact dependency revisions, amendment history and idempotent writes.
- Workspace membership, declared source restrictions and separate review authority.
- Scoped corrections, trusted replay and explicit reuse approval.
- Session opening without history and bounded context retrieval.
- SQLite persistence, synthetic examples and automated quality checks.

Compatibility may change during the alpha. This version does not imply a package release or production readiness.
